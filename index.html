🔍 DocSearch APT Repository

Official Debian / Ubuntu / Linux Mint APT repository for DocSearch — local cross-platform document search engine with OCR and system tray.

1. Add the DocSearch APT source:
echo "deb [trusted=yes] https://gops.github.io/DocSearch/ ./" | sudo tee /etc/apt/sources.list.d/docsearch.list
2. Update package lists and install DocSearch:
sudo apt update
sudo apt install docsearch
3. Automatic Upgrades:

From now on, standard sudo apt update && sudo apt upgrade will automatically update DocSearch whenever new versions are released.
